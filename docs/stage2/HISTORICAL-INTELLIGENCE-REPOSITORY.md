## 四、定向反向回溯工具使用指引（Backward-Trace Engine）

历史信息库沉淀后，日常巡检和研究分析**无需翻阅海量历史旧闻**。遇到任何企业、项目、省份或赛道线索时，通过本地 Python 引擎秒级调用：

### 4.1 常用查询命令

```bash
# 1. 按企业或项目名称检索（支持中英文/简写/代码）
python scripts/stage2/query_history.py "光宝"
python scripts/stage2/query_history.py "SCG"
python scripts/stage2/query_history.py "Pacifico"
python scripts/stage2/query_history.py "五新智能"
python scripts/stage2/query_history.py "博威"

# 2. 按项目编号精准检索（秒级输出全周期时间线演进）
python scripts/stage2/query_history.py PRJ117
python scripts/stage2/query_history.py PRJ266

# 3. 按核心省份筛选项目组合
python scripts/stage2/query_history.py --province "北宁" -n 10
python scripts/stage2/query_history.py --province "广宁"
python scripts/stage2/query_history.py --province "海防"

# 4. 按产业赛道筛选
python scripts/stage2/query_history.py --sector "半导体"
python scripts/stage2/query_history.py "数据中心"

# 5. 查看越南国家级 FDI 宏观时间序列基石
python scripts/stage2/query_history.py --macro
```

### 4.2 程序化调用接口（供 Stage 2 及日常巡检脚本集成）

```python
from scripts.stage2.query_history import query_project

# 当日巡检命中 '光宝科技' 时，自动提取历史背景以辅助大模型判断
history_records = query_project("光宝科技", limit=1)
if history_records:
    print('发现历史项目背景：', history_records[0]['project_name_cn'])
```
