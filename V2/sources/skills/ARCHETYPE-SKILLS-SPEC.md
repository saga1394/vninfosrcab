# 5 大业务技能与 5 大底层驱动双层解耦规范 V2 (Two-Layer Skill & Driver Architecture)

> **版本**：v2.0.0（严格落实 8492 QA 审查报告“补丁 2：双层解耦”）  
> **核心原则**：彻底解除业务语义与网络协议的耦合（消除 5×5=25 倍代码膨胀），系统收敛为**“5 大上层业务原型认知技能 + 5 大底层无状态协议驱动”**。

---

## 一、 双层解耦架构全景图

```
+-----------------------------------------------------------------------------------+
| 上层：业务认知层 (5 Archetype Cognitive Skills) —— V2/sources/skills/              |

|  2. park-news-inspector     (园区招商动态识别，提取供地面积、奠基、签约实体)        |
|  3. gazette-table-parser    (法定公文批复识别，过滤乡村基建、提炼制造业环评产能)    |

                                          │ 统一调用协议路由 (依卡片 protocol_driver)
```
